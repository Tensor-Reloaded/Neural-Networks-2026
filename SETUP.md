## Local setup

Tested on Python 3.13.5. Use a separate environment for this repository:

`requirements-lab01-tested.txt` records the exact direct package versions used for the saved outputs. The normal requirements file allows compatible updates.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lab01.txt
python -m jupyter lab Lab01/FirstLab.ipynb
```

Windows PowerShell activation: `.venv\Scripts\Activate.ps1`.

Select the environment's Python kernel. If using a Jupyter server from another environment, register this kernel with `python -m ipykernel install --user --name nn-2026 --display-name "Neural Networks 2026"`.

For Colab, upload the notebook through File → Upload notebook. Run the setup cell. If an import is missing, run `%pip install numpy matplotlib` in a new cell. GPU is unnecessary. These new files are local until pushed, so their GitHub/Colab URLs are not yet public.

## Verify or rebuild

`python scripts/build_lab01.py` regenerates the authored notebooks and clears their outputs. Only run it when intentionally regenerating the pack, since it overwrites edits to those two notebooks.

```bash
python -m jupyter nbconvert --execute --to notebook --inplace Lab01/FirstLab.ipynb
python -m jupyter nbconvert --execute --to notebook --inplace Lab01/LearningPreview.ipynb
python scripts/export_lab01.py
```

Restart the kernel and Run All to check a clean session. Trust a locally generated notebook if Jupyter suppresses its animation. The export script embeds the plot frames and playback code, labels the figures, and replaces remote animation icons with text controls.
