How one update works


Use the current weights to make a prediction, then correct them using the true label.


    

  1. Calculate the scorez = w₁ · x₁ + w₂ · x₂ + b
    2. 

  2. Choose a label
    If z ≥ 0 predict +1If z < 0 predict −1
    3. 

  3. Measure the mistakeerror = prediction − true label
    4. 

  4. Update both weights and the biasw₁ ← w₁ − η · error · x₁
    w₂ ← w₂ − η · error · x₂
    b  ← b  − η · error
    η is the learning rate. Use the same error in all three updates.

Why ±2?
Our labels are −1 and +1. A wrong prediction gives +1 − (−1) = +2 or −1 − (+1) = −2.
Correct prediction → error = 0 → no change.
