2 · Masks: select first, then count (12–22 min)¶

Official NumPy exercise data: 1 = spam, 0 = ordinary mail. No classifier is trained here. & combines array conditions; use parentheses. The count of True values is a reduction.

A1 (5 min): return (TP, FP, FN, TN) using masks, then compute accuracy. TP = actual 1 / predicted 1; FP = actual 0 / predicted 1; FN = actual 1 / predicted 0; TN = actual 0 / predicted 0. Inputs are nonempty, same-length 1D binary arrays. Continue the official NumPy exercises for F1 and benchmarking; MetricsPractice.ipynb provides extra explanations after class.

3 · Copies matter when replacing matrix columns (22–30 min)¶

The homework's Cramer matrices replace a column. A shallow copy of a nested Python list still shares the rows. NumPy slices may also share data. Predict which originals change.

shallow-copy mutation reaches original: [[99, 1], [1, 2]]
row copies preserve original: [[2, 1], [1, 2]]
NumPy original: [[99, 1], [1, 2]] independent column: [2, 1]

4 · A·x = B: equations and transformations (30–42 min)¶

Two ticket bundles cost 7 and 8 units: 2x + y = 7, x + 2y = 8. Every equation is a line. The intersection satisfies both. A zero determinant means no inverse: the system may have no solution or infinitely many.

solution: [2. 3.] residual: [0. 0.]

On paper: determinant ad−bc = 3. Replace the first column with B: determinant 6 → x=2. Replace the second column: determinant 9 → y=3. Verify both equations.
